# Sunday 22 November 2026 — The World in One Day

A one-image newspaper summing up the world's news of Sunday 22 November 2026:
35 stories across 7 regions, with the COP31 final text going to a Sunday vote,
Iran's claimed strikes on US bases in Bahrain, and Russia's overnight barrage
of 186 drones over Ukraine as the three lead stories — plus a UTC timeline, a
numbered world map, 22 more briefs, and a DATE CHECK box that names what was
deliberately left out.

## Entry

- `entry.png` — the finished front page (1024×1024, under 1 MiB)
- `main.ts` — Node 22 program (standard library only) that copies `entry.png`
  to `/output/entry.png`

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
